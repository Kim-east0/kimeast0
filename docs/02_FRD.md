# FRD — 현장별 공정·기성 대시보드

## 한눈에 보기

- **무엇을 정리했나:** 화면에서 무엇을 누르면 프로그램이 무엇을 하고, 화면에 무엇이 보이는지 기능 21개로 정리했습니다.
- **필터:** 월·지역·공사 유형·현장 4개를 4개 페이지가 함께 씁니다. 숫자·차트·표·CSV·AI가 모두 같은 범위를 따릅니다.
- **누적과 당월 구별:** 누적기성액은 자료의 값 그대로, 당월기성액은 "이번 달 누적 − 바로 전달 누적"입니다. 전달이 없는 2025-10은 "계산 불가"입니다. 수금액은 자료에 없어 다루지 않습니다.
- **오류:** 오류가 나도 지금 자료는 그대로 두고, 어느 행의 무엇이 문제인지 알려 줍니다. AI가 실패해도 대시보드와 CSV는 계속 씁니다.
- **시안과 다른 점:** 시안에 있는 목표 기성률·수금률·리스크 등급 등 자료에 없는 항목은 만들지 않습니다. 목록은 맨 아래 "시안과 다른 점"에 있습니다.

> 교육용 가상 자료입니다. 실제 동일토건의 계약·현장·실적이 아닙니다. 계산·검증 기준은 `data/데이터설명.md`와 `data/검산표.md`를 따릅니다.

## 3. 역할별 표

| 역할 | 맡는 일 | 맡지 않는 일 |
|---|---|---|
| 사용자(공무팀 담당자) | 파일을 고름, 필터를 고름, 순위·표를 눌러 기록을 확인, CSV를 내려받음, 질문을 입력함 | 숫자를 직접 계산하지 않음 |
| 프로그램(계산·검사) | 파일 검사, 기성률·공정률·공정차이·상태·당월기성액 계산, 정렬, 필터 적용, CSV 만들기, 오류 안내, AI에 보낼 자료 정리 | 원인 추정, 일정 예측, 자료에 없는 값 만들기 |
| AI(설명) | 프로그램이 계산한 숫자와 기록된 상황·계획된 대응을 근거로 쉬운 말로 설명 | 숫자 계산, 원인 확정, 대응의 완료·효과 단정, 실제 준공일·미수금 답변 |

근거: 계산은 프로그램이 해야 같은 입력에 같은 결과가 나오고, 검산표와 맞는지 자동 검사할 수 있습니다.

| 항목 | 계산 방법 | 예시 (검산표 숫자) |

| 상태 개수 | 선택 범위 현장을 상태별로 셈 | 9월 정상 6 · 주의 3 · 점검 3 |

| 표시 | 계산 중에는 반올림하지 않고 마지막에 %·pp·백만원을 소수 첫째 자리로 반올림 | 28,878.7백만원 |
| 자료 없음·분모 없음 | "자료 없음" 또는 "계산 불가". 0%로 대체하지 않음 | 빈 범위 |
